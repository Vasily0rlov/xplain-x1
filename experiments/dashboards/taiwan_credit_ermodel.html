How to read this schema

Each COMPONENT (Layer F certified term) uses one or more FEATUREs (its support, via the COMPONENT_SUPPORT junction) and is physically carried by one or more UNITs (measured, via CARRIER — a unit can carry a term through a collinear feature it reads, which is why CARRIER is distinct from COMPONENT_SUPPORT). Components sum into the FUNCTION_F (f = μ + Σ terms), which drives the DECISION via its link. FEATUREs are clustered into COLLINEARITY_GROUPs; a ROUTE (Layer S) certifies reliance on a group — the coarse, carving-invariant claim, distinct from any single unit or component.
